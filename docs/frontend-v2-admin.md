# 账户与邀请码管理

管理入口为同源 `/admin`，不出现在玩家导航。维护者密码由 `ADMIN_PASSWORD` 环境变量提供，至少16字符；没有默认密码，也不能通过网页首次设置。管理登录使用独立 `td_admin_v2` HttpOnly Cookie，固定两小时并在进程重启后失效。

管理API契约见 `openapi-admin-v2.1.json`。账户“移除”采用可恢复停用：大厅释放成员；对局和复盘保留离线席位及历史。账号改名只允许无房间或大厅期；清除头像进入现有延迟回收；注销会话、停用和密码重置都会收回旧设备授权。

注册邀请码有效期为5分钟至30天，默认7天。token只在创建或重新生成响应中返回一次，数据库只存哈希；列表中的ID用于撤销。重新生成会保留旧记录并创建新ID。密码重置码默认30分钟，绑定指定账号，使用后撤销该账号其他未使用重置码并注销全部会话。

账户库schema版本为3，新增停用状态、邀请码创建/撤销时间和不含秘密的管理操作记录。管理接口不会返回密码哈希、会话ID、邀请码哈希或管理员密码。
